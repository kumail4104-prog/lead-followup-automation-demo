# lead-followup-automation-demo
## What this project is about
This project shows how a business can respond to new leads, keep conversations organized, and guide interested people toward booking an appointment

## How the workflow works
A new lead shares their details through a form..." "...The information is organized in the CRM..." "...followed up with a helpful message, and moved toward an appointment when the lead is interested.

## Tools Used

- n8n for workflow automation
- CRM for organizing lead information
- form for collecting new lead details
- follow up messages for staying in touch
- appointment booking for interested leads
